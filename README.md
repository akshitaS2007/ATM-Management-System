# ATM-Management-System
A full-stack ATM simulation built with React, Node.js/Express, and SQLite — supports login, balance checks, deposits, withdrawals with cash denomination selection, and transaction history.

## Features
- Card number + PIN login authentication
- Real-time balance inquiry
- Deposit money with daily deposit limit
- Withdraw money with cash denomination selection
- Daily withdrawal limit and balance checks
- Full transaction history, newest first
- Input validation on frontend and backend

## Tech Stack
- Frontend: React
- Backend: Node.js, Express
- Database: SQLite
- API: REST

## How to run
1. Clone the repo
2. Run `cd backend && npm install && node server.js`
3. In a separate terminal, run `cd frontend && npm install && npm start`
4. Open `http://localhost:3000`
